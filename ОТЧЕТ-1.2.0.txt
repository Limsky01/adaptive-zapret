Adaptive Zapret 1.2.0

Изменения интерфейса:
- «Диагностика» и «Обновления» перенесены в «Дополнительно»;
- «Приложения → Сейчас» показывает живые TCP и недавние UDP-подключения;
- список обновляется автоматически каждые две секунды;
- полная накопленная карта перенесена в «Приложения → История»;
- главная страница отображает состояние карточками.

Автоматическое переподключение:
- для выбранного IPv4 TCP закрывается только точное соединение процесса к IP:порту через системный Windows API SetTcpEntry;
- программа ждёт пять секунд и проверяет появление нового соединения;
- для UDP создаётся точечная временная блокировка процесса, IP и порта на пять секунд, затем правило удаляется;
- действие выполняется при первой стратегии и после «Не работает — следующая».

Ограничение: принудительный сброс TCP в этой версии поддерживает IPv4. IPv6 не завершается принудительно; следующая новая попытка всё равно получит выбранную стратегию.
