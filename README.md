# Adaptive Zapret 1.0

Локальное приложение для Windows 11 x64, которое связывает сетевые цели с
программами, управляет точечными правилами и подбирает профиль winws без ручной
пересылки журналов.

Для обычного запуска достаточно дважды щёлкнуть `AdaptiveZapret.cmd`: он запросит
права администратора и откроет графический интерфейс.

## Первый запуск

Откройте PowerShell от имени администратора:

```powershell
cd C:\adaptive-zapret
Set-ExecutionPolicy -Scope Process Bypass
.\AdaptiveZapret.ps1 selftest
.\AdaptiveZapret.ps1 setup
.\AdaptiveZapret.ps1 ui
```

`engine-install` загружает последний ZIP официального проекта Flowseal с GitHub,
сохраняет SHA256 архива в `config/engine-receipt.json` и не устанавливает ничего
вне папки приложения. Вместо загрузки можно указать существующую папку Flowseal:

`setup` также загружает Sysmon только с `download.sysinternals.com`, проверяет
цифровую подпись Microsoft, применяет комплектную сетевую конфигурацию и запускает
фоновый сборщик.

```powershell
.\AdaptiveZapret.ps1 engine-set 'D:\zapret-discord-youtube'
```

## Обычная работа

Сборщик работает скрыто и сохраняет историю локально. В интерфейсе:

1. На вкладке «Приложения → Сейчас» выберите живое подключение. Таблица обновляется каждые две секунды; накопленная карта находится в «Истории».
2. Выберите нужную цель процесса и нажмите «Подобрать zapret».
3. Проверьте подключение в игре.
4. На вкладке «Подбор» выберите «Работает» или «Не работает — следующая».

При каждой смене профиля программа закрывает только выбранное IPv4 TCP-соединение
через Windows IP Helper API, ждёт пять секунд и проверяет повторное подключение.
Для UDP на пять секунд создаётся точечное исходящее правило для процесса, IP и
порта. Игра и остальная сеть не перезапускаются.

Рабочая стратегия сохраняется в `data/rules.json`. Отправлять CSV или JSONL
кому-либо не требуется. Кнопка «Всё напрямую» останавливает только управляемый
экземпляр winws и удаляет только правила брандмауэра с префиксом
`AdaptiveZapret-`.

## Обновления

На вкладке «Обновления» можно сохранить HTTPS-адрес подписанного канала и затем
устанавливать новые версии кнопкой «Проверить и обновить». Программа проверяет
RSA-подпись манифеста и SHA-256 ZIP, сохраняет резервную копию, обновляет только
файлы программы и перезапускается. Папки `data`, `config` и `engine` сохраняются.
Если канал временно недоступен, ZIP можно выбрать кнопкой «Установить ZIP вручную».
Журнал обновления: `data\update.log`; резервные копии: `data\runtime\update`.

## Командная строка

```text
status                         состояние сборщика, Sysmon и движка
setup                          полная первичная настройка
sysmon-install                 установка официального Sysmon
start / stop                   фоновый сбор
apps                           обновить очищенную карту
focus BrokenArrow              показать цели процесса
learn BrokenArrow              выбрать наиболее вероятную цель автоматически
learn 'Proc|domain|IP|443|TCP' начать подбор для точной цели
test pass|fail|skip             локальный результат текущей попытки
rules                          сохранённые правила
rule-add 'Proc|domain|IP|443|TCP|direct|'
rule-remove ID
apply                          применить сохранённые правила
direct                         остановить обход и снять свои блокировки
autostart-on / autostart-off   применение правил при входе в Windows
export                         создать general (AUTO).bat
ui                             графический интерфейс
selftest                       встроенная диагностика
```

## Безопасность

- Правила всегда требуют процесс, точный порт и точный домен или IP.
- Шаблоны доменов и системные процессы запрещены.
- `block` требует точный IP и известный путь программы; глобальная блокировка не
  создаётся при отсутствии пути.
- Приложение не завершает чужие процессы winws. При конфликте оно останавливается
  с сообщением.
- Подбор меняет профиль только между попытками подключения, не внутри игровой
  сессии.
- После неудачного перебора автоматически восстанавливается direct.

Sysmon хранит чувствительную историю сетевой активности в `data`. Эти файлы не
нужно публиковать. Байтный объём трафика Sysmon Event ID 3 не предоставляет;
приложение хранит события соединений, цели и результаты стратегий.
