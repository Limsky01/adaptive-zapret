# 1.0.4

- Исправлено пустое серое поле карты приложений в Windows PowerShell 5.1: таблица заполняется явно, без ненадёжной привязки `Object[]` к WinForms.
- Добавлены счётчик показанных подключений и время обновления карты.
- Пустой цикл сбора больше не перезаписывает последнюю рабочую карту приложений.

# 1.0.3

- Исправлена кодировка UTF-8 BOM загрузчика и интерфейса для Windows PowerShell 5.1.
- Устранена ошибка ParserError до создания журнала запуска.

# 1.0.2

- Добавлен отдельный STA-загрузчик интерфейса.
- Журнал запуска создаётся в корне приложения до загрузки WinForms и модулей.
- Ошибка раннего запуска теперь показывается в диалоговом окне и не исчезает вместе с консолью.
- Исправлен путь запуска после запроса прав администратора.

# 1.0.0

- Полный сбор TCP/UDP/DNS через Sysmon и резервный TCP-сбор.
- Фоновый сборщик и очищенная карта приложений.
- Локальные правила `direct`, `zapret`, `block` с защитными ограничениями.
- Обнаружение существующего winws и установка официального релиза Flowseal.
- Изолированный локальный подбор TCP/UDP-профилей с `pass/fail/skip`.
- Немедленный откат в direct после исчерпания профилей или по команде.
- Сохранение проверенных правил, одновременные непересекающиеся профили winws.
- Графический интерфейс, автозапуск и экспорт `general (AUTO).bat`.
- Двойной клик по `AdaptiveZapret.cmd` с безопасным запросом прав администратора.
- Встроенная самопроверка и отдельный тест правил.
