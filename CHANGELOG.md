# 1.3.0

- Ядро подбора заменено: вместо упрощённых самодельных профилей запускаются полные стратегии `general*.bat` установленного релиза Flowseal.
- Сохраняются все параметры Flowseal: цепочки `--new`, fake-файлы, overlap, fooling, cutoff, L7 и игровые фильтры; меняются только временные списки целей сценария.
- PTR-имя Sysmon больше не используется как домен/SNI. Источник имени хранится отдельно; неизвестная цель фильтруется по IP.
- «Запись действия» собирает единый сценарий TCP+UDP для Steam, YouTube и игр и тестирует его целиком.
- Добавлены команда запуска и диагностический журнал winws; положительный результат нельзя принять, если профиль не увидел новых пакетов.
- Каждый успех перепроверяется второй новой попыткой. Старые правила синтетических профилей безопасно отключаются.
